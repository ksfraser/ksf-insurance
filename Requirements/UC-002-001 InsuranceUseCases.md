# UC-002-001 InsuranceUseCases: Insurance Planning Use Cases

**Related:** BR-002 InsurancePlanning, FR-002-001..FR-002-007

## Actors
- **Advisor** — FA staff user managing a client's insurance plan.
- **Client** — FA customer (debtor_no) whose insurance is being planned.

## Use cases
- **UC-002-001 Capture Insurance Needs** — Advisor enters income/debt; system computes need.
- **UC-002-002 Value In-Force Policies** — System analyzes cash/surrender values.
- **UC-002-003 Compare Policies** — Advisor compares competing policies.
- **UC-002-004 Project Premiums** — System projects future premium outlays.
- **UC-002-005 Assess Risk** — System assesses risk profile for recommendation.
